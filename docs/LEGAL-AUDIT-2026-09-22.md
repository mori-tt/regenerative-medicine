# 医療広告・薬機法・著作権監査（2026-09-22）

これは公開コンテンツと実装に対する編集監査であり、弁護士による意見書ではありません。法令違反がないことや、紛争が起きないことを保証するものではありません。

## 結論

現行の設定では広告枠は空（`bannerAds.home/article = null`）で、広告主・医療機関への予約・購入導線は実装されていません。記事は研究・承認・制度を説明する一般情報として構成され、特定医療機関の治療を販売するページにはなっていません。

ただし、医療機関や製品を特定できる広告、広告費を受けた記事、予約・購入リンクを追加した時点で、ページ単位・リンク先を含めた再審査が必要です。医療広告は媒体名や免責文だけで対象外にはなりません。厚生労働省は、誘引性と医療機関等の特定性を満たす表示を広告規制の対象として扱い、最新の事例解説書・ガイドライン・Q&Aを公開しています。[厚生労働省の医療広告資料](https://www.mhlw.go.jp/stf/newpage_53822.html)

## 医療広告

- 広告設定を確認し、現在配信なしと判定しました。
- 「最も優れた」「必ず治る」などの比較優良・保証表現、患者体験談、ビフォーアフター、予約CTAを対象コードから抽出し、明白な掲載は確認しませんでした。
- 監修予定者のプロフィールは、監修予定であること、記事単位の確認が未完了であることを表示します。医師名・資格・所属が治療効果の保証に見えないようにしています。
- 広告掲載時は、広告主、広告である表示、掲載期間、リンク先、利益相反、審査者、審査日をJSON台帳に記録する必要があります。

## 薬機法

記事中の承認製品名・研究情報は、現在は出典付きの教育的説明として掲載されています。販売、提供機関への誘導、製品購入導線はありません。

薬機法66条は、医薬品・医療機器・再生医療等製品の名称、効能、効果、性能に関する虚偽・誇大広告と、医師等が保証したと誤解される表示を禁じています。68条は承認前の対象製品について、名称・効能・効果・性能の広告を禁じています。[厚生労働省「医薬品等の広告規制」](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iyakuhin/koukokukisei/index.html)

したがって、将来の広告では研究結果を広告主の製品の効果として再利用せず、承認範囲・対象疾患・条件及び期限・主なリスク・代替治療・費用を個別に確認します。未承認・適応外を扱う広告は、一般向け広告として出稿しない前提で審査します。

## 著作権・画像

論文・公的資料の本文を転載せず、独自に要約して出典URLを表示しています。出典リンクだけで転載許諾になるとは扱っていません。文化庁は、引用には公表、公正な慣行、正当な範囲、明瞭な区別、主従関係、出所表示などの検討が必要と説明しています。[文化庁の著作権FAQ](https://www.bunka.go.jp/seisaku/bunka_gyosei/kibankyoka/faq/index.html)

画像については、実ファイルを同梱している7点すべてが `manual_rights_check_required` です。Pixabay・Unsplashのライセンス名を記録していますが、現在の出典URLには検索ページが含まれ、個別画像・取得日・ライセンス条件・権利者許諾の証跡が不足しています。そのため `npm run build:target -- lolipop` に `NEXT_PUBLIC_PUBLICATION_MODE=production` を指定すると、`npm run check:rights` が失敗します。権利確認前に本番公開できないようにした実装上の措置です。

手作業では、各画像の個別ページ、ライセンス版、取得日、権利者、商用利用・改変・再配布・人物利用の条件を保存し、`rightsStatus` を `verified` に変更してください。千原先生の写真は、写真提供元からサイト掲載・翻訳ページ・広告隣接表示を含む許諾を別途取得します。

## 追記（2026-09-23）：表現リスクの自動検知を追加

`npm run check:article-content`（`prebuild`で自動実行）に、医療広告ガイドラインが問題視する表現カテゴリの検知を追加した。対象は日本語原稿（title・description・points・sections）、英語・中国語の翻訳本文、evidenceファイルの追記段落・訂正文のすべてで、以下の4カテゴリを走査する。

- `comparative_superiority_claim`：日本一・世界一・業界No.1などの比較優良表現
- `guarantee_or_absolute_claim`：絶対安全・100%治る・副作用ゼロなどの保証表現
- `patient_testimonial_cue`：体験談・お客様の声・ビフォーアフターなどの表現
- `unqualified_hype_claim`：唯一の治療法・世界初の治療・奇跡の治療などの誇大表現

一致は自動エラー（ビルド失敗）にはせず、`advisories`に記録して人手レビューを促す設計にした。否定文（「絶対安全ではない」等）や記事の趣旨説明（「画期的な発表と実用化の距離を分ける」等）でも一致し得るため、機械的な合格・不合格の判定はできない。現時点（2026-09-23）の走査では、原稿本文に該当する明確な違反表現は見つかっていない（既知の限定的一致2件はいずれも安全側の文脈）。この仕組みは将来の原稿追加・改稿時の回帰検知であり、本監査の結論や法務専門家によるレビューの代わりにはならない。
