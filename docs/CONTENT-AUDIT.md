# コンテンツ監査と公開後の運用

このメモは、再生医療・幹細胞の情報サイトとして公開前に行った内容監査と、残る対応事項をまとめたものです。医学的な監修意見や弁護士の法的意見書ではありません。

## 今回反映した内容

- 承認と健康保険の適用を別の制度として説明する表現に修正。
- 承認品目一覧、保険上の取扱い、jRCT、国税庁の医療費控除を出典に追加。
- 記事カードと記事詳細に「一般情報・編集部記事」「位置づけ：一般情報」を表示。
- 監修者の所属学会・資格表示が、特定の治療や製品の推奨を意味しないことを明記。
- 執筆者表示の「仮称」を削除し、実際の編集部表記に統一。
- 大学・研究機関、学会、公的機関の情報源ページを追加。
- 全208記事を `src/content/article-review-records.json` に登録し、公開予定日、医学・法務・根拠・分かりやすさの確認状態、リスクフラグ、監修記録欄を記事単位で管理。
- 2026-09-21以降、初期候補10本を含めて月10本を上限に予約日を付与。未来日記事は一覧・検索・カテゴリ・詳細ページ・サイトマップ・静的生成の対象外。
- 全208記事に、研究デザイン・対象者・比較・評価項目・追跡期間・限界を確認する「論文を読むときの注意点」またはカテゴリー別の根拠確認セクションを追加。英語・中国語版にも同趣旨を追加。
- `src/content/article-evidence.ts`で、PubMedのレビュー、メタ解析、研究方法論、幹細胞の安全性・臨床移行に関する参考論文をカテゴリー別に管理。これらは記事の背景を確認する参考資料であり、各記事の個別治療の効果や安全性を直接証明する引用ではない。

## 公開前に必ず完了させること

### 自動監査の扱い

台帳の `needs_medical_review`、`needs_legal_editorial_review`、`needs_manual_readthrough` は、未確認の箇所を見落とさないための仮判定です。出典URLが登録されている記事も、リンク先の内容が本文の主張を直接支えているか、公開時点で有効か、医学的に正確かは手作業で確認してください。台帳の `initial-candidate` は公開順の候補であり、公開許可ではありません。

自動棚卸しでは、208記事すべてに出典URLが登録されていました。本文の語句からは、効果・治療に関する確認対象が134記事、安全性・リスクが85記事、費用・制度が51記事、規制・広告が26記事、個別判断に関わる内容が58記事、応急手当などの一般的な健康指示が5記事ありました。これらは問題記事の確定数ではなく、監修・出典照合を優先するための抽出数です。

今回追加したPubMed論文は、公開時点の最新の結論を自動的に保証するものではありません。論文の対象・介入・アウトカムが本文のどの記述を支えるかは、記事ごとに医師または医学知識のある編集者が確認し、確認日・確認範囲・修正内容を監修台帳へ記録します。医中誌Webの検索結果を追加する場合も、抄録だけで結論を広げず、入手可能な原著本文・掲載誌情報・利益相反を確認してから採用します。

### 医学・監修

1. 記事ごとに、医学的確認を実施した日、確認範囲、修正点、確認者、利益相反を記録する。
2. 実際に確認されていない記事へ、監修済み・医学的確認済みと表示しない。
3. 千原良友先生の氏名、所属、資格、経歴、所属学会、監修者表示について、本人または所属先の掲載許諾を保存する。
4. `public/images/doctor-chihara.jpg` のウェブ掲載・再配布許諾を、写真の権利者から取得する。
5. 「一般的な情報」と「個別の診断・治療の助言」を記事の冒頭と問い合わせページで区別する。

### 制度・事実確認

1. 承認品目、承認条件、保険上の取扱いは、公開直前にPMDA・厚生労働省で確認する。
2. 治験・臨床研究の記事はjRCTの検索導線を掲載し、登録情報と実際の参加可否を混同しない説明にする。
3. 税制や高額療養費は、国税庁・厚生労働省・加入保険者の最新情報へリンクする。
4. 「世界初」「画期的」「確立」などの表現は、対象疾患・承認範囲・条件を明記できる場合だけ使う。
5. 各記事の更新日とは別に、出典を最後に確認した日を管理する。

### 運営・法務

1. 運営者の正式名称、所在地、連絡先、訂正窓口、個人情報の保存期間を確定して掲載する。
2. 監修契約、写真許諾、引用条件、広告契約、利益相反申告を保存する。
3. 医療機関・クリニックの広告を掲載する場合は、広告主、広告表示、リンク先、審査記録を残す。
4. 医療広告に該当する可能性があるページは、公開時点の厚生労働省ガイドラインと事例解説書で再確認する。
5. 問い合わせフォームは、Lolipop本番環境で送信、返信、迷惑メール判定、障害時の表示を実メールで確認する。

## 公開後の定期運用

- 月1回：リンク切れ、問い合わせ、フォーム送信、主要な公的ページの更新を確認。
- 四半期ごと：承認品目、制度、jRCT、広告表現、記事の更新日を確認。
- 半年ごと：全記事の出典と医学的表現を棚卸しし、必要な記事を再確認。
- 制度改正・安全性情報・重大な訂正が出た場合：定期日を待たずに該当記事を一時非公開または訂正する。

## 公開切替の条件

`NEXT_PUBLIC_PUBLICATION_MODE=production` と `NEXT_PUBLIC_SITE_INDEXABLE=true` は、上記の許諾、運営者情報、監修記録、制度確認、法務確認が完了してから設定する。設定値を変更しただけでは、医学的な確認や法的適合性は成立しない。

手作業で必要な確認の一覧は [`MANUAL-LEGAL-CHECKLIST.md`](./MANUAL-LEGAL-CHECKLIST.md) にまとめています。
