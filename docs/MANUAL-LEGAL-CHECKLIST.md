# 手作業で完了させる公開前チェック

このファイルは、コードで自動化できない確認だけをまとめたものです。確認が終わるまでは、`NEXT_PUBLIC_PUBLICATION_MODE=preview` と `NEXT_PUBLIC_SITE_INDEXABLE=false` を維持してください。

## 公開を止める確認

- [ ] 運営者の正式名称、実際の所在地、問い合わせ用メールアドレスを確定し、`NEXT_PUBLIC_OPERATOR_NAME`、`NEXT_PUBLIC_OPERATOR_ADDRESS`、`NEXT_PUBLIC_CONTACT_EMAIL` に設定した。
- [ ] 森 崇裕さんが編集者として表示されることと、編集者住所を公開することを確認した。住所を公開したくない場合は、公開用の事業所住所に差し替える。
- [ ] 千原良友先生の氏名、資格、経歴、所属、写真、監修者表示について、本人または所属先からウェブ掲載の書面許諾を取得した。
- [ ] 写真について、撮影者または権利者からウェブ掲載・再配布の許諾を取得した。
- [ ] 監修者が実際に各記事を確認した日、確認範囲、修正点、利益相反を記事ごとに記録した。
- [ ] 未確認の記事に監修済み表示を付けていない。監修者表示を有効にする場合だけ `NEXT_PUBLIC_MEDICAL_REVIEWER_ENABLED=true` にした。
- [ ] 監修済みとして公開する各記事の `review`、確認日、確認範囲、出典を実際の記録と照合した。

## 全記事の確認

- [ ] 記事ごとに、対象疾患、研究段階、承認範囲、保険適用の有無、自由診療との違いを最新の公的資料で確認した。
- [ ] 効果・安全性・副作用・費用について、断定、誇張、恐怖をあおる表現、個別の治療推奨がないことを確認した。
- [ ] 「世界初」「画期的」「最先端」「確立」などの表現は、根拠、対象、条件、時点を示せるものだけ残した。
- [ ] 医療費控除、高額療養費、承認品目、再生医療等提供計画の説明を、公開直前の国税庁・厚生労働省・PMDAの資料と照合した。
- [ ] 日本語・英語・中国語の各ページを実際に読み、翻訳の誤り、意味の逆転、未翻訳の文を修正した。
- [ ] すべての画像、図版、引用、転載について、利用許諾または適法な引用条件を確認した。

## 広告・収益化を始める場合

- [ ] 広告主、報酬、掲載期間、リンク先、広告表現、審査結果を記録する運用を作った。
- [ ] 広告・PR・アフィリエイトであることを読者がすぐ分かる位置に表示した。
- [ ] 広告費と記事の評価、監修者の推薦、ランキング表示を分離した。
- [ ] 医療機関の広告を掲載する場合、公開時点の厚生労働省「医療広告等ガイドライン」と事例解説書を確認した。
- [ ] 広告主との関係、紹介料、利益相反を編集方針と該当ページに反映した。

## 問い合わせ・個人情報

- [ ] フォームの利用目的、保存期間、保存場所、委託先、アクセス権限、安全管理、第三者提供、開示・訂正・削除の窓口を実際の運用に合わせてプライバシーポリシーに記載した。
- [ ] 病歴、検査結果、画像などの要配慮個人情報を送信しないよう、フォームと注意書きを実際に確認した。
- [ ] 本番メールで送信、受信、返信、迷惑メール判定、障害時の表示を確認した。
- [ ] 問い合わせに医療相談が届いた場合の返信文と、緊急時の案内を決めた。

## 公開操作

- [ ] 上記の証憑（許諾、監修記録、出典確認、広告審査、プライバシー確認）を保存した。
- [ ] `NEXT_PUBLIC_PUBLICATION_MODE=production` と `NEXT_PUBLIC_SITE_INDEXABLE=true` を設定した。
- [ ] 本番ドメインを `NEXT_PUBLIC_SITE_URL` に設定した。
- [ ] `npm run typecheck`、`npm run build`、`npm run check:export` が成功した。
- [ ] 公開後に、トップ、記事一覧、記事詳細、運営者情報、監修ページ、問い合わせ、robots.txt、sitemap.xmlを実機で確認した。

## コード側で設定済みの保護

- 本番モードでは、監修記録のない記事を一覧・検索・カテゴリ・詳細ページ・サイトマップから除外します。
- 本番モードかつ検索公開の場合、運営者名、所在地、連絡先がないとビルドを停止します。
- 医師プロフィールは既定で非表示です。許諾と確認が済んだ場合だけ環境変数で有効化します。
