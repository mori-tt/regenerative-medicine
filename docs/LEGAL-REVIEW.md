# 法務・医療公開前チェック（2026-09-19）

この文書は弁護士による法的意見書ではありません。正式公開前に、運営者・掲載許諾者・医療広告に詳しい専門家が確認するための監査メモです。

## 現時点の判定

現在の設定は `publication.mode=preview`、`showPreparationNotices=true` です。記事は監修前原稿として表示され、`reviewedAt` が空欄のため医師監修済み記事としての表示・Article構造化データ・記事サイトマップ掲載には進みません。日本再生医療学会の特集ページも、preview中は監修前表示とnoindexを維持します。

本文を確認した範囲では、個別治療の効果・安全性を断定する表現、患者体験談、ビフォーアフター、他院との比較優良表現、治療予約への誘導は確認できませんでした。出典を示し、研究・承認・自由診療を分け、個別判断は医師へ相談する構成です。

## 公開前に必ず確認する事項

1. 各記事について、実際の医師監修の実施日、確認範囲、修正履歴、利益相反、掲載許諾を記録する。日付だけを入力して監修済みにしない。
2. 千原良友先生の氏名・経歴・所属学会・監修者表示について、本人または所属先から掲載許諾を取得する。
3. `public/images/doctor-chihara.jpg` について、写真の著作権者からウェブ掲載・再配布の許諾を確認する。出典リンクだけでは利用許諾の代わりにならない。
4. 運営者の正式名称、住所、連絡先、訂正受付窓口、プライバシー通知を確定する。問い合わせや解析を追加する場合は、取得情報・利用目的・委託先を更新する。
5. 医療機関から広告費を受け取る場合は、広告であること、広告主、リンク先、表現審査、利益相反を記録し、編集記事と視覚的にも分離する。
6. 医療機関の広告・誘引を含むページを公開する場合は、公開時点の厚生労働省「医療広告等ガイドライン」と事例解説書を確認する。免責文や `rel=sponsored` だけでは適法性は確保できない。
7. 再生医療等安全性確保法、薬機法、関連通知は更新されるため、制度・承認・提供計画に関する記述は公開直前に厚生労働省・PMDAの最新資料と照合する。

## 公開切替の条件

`NEXT_PUBLIC_PUBLICATION_MODE=production` と `NEXT_PUBLIC_SITE_INDEXABLE=true` への変更は、上記の監修・許諾・運営者情報・法務確認が完了した後に行う。実際の確認がない状態で、監修済み・公開済みとして表示することは禁止する。
