# デザイン・UI見直し（2026-09-22）

## 変更内容

- 深緑・生成り・白を中心に、見出し、本文、補足、リンクの役割を統一。
- 本文はスマホでも16px、記事一覧の概要は14pxに。見出しの改行と行間も調整。
- トップの重複した「目的から探す」をテーマ別案内に集約。入門と記事一覧の入口を並べて表示。
- 日・英・中のトップに記事カードを4件表示。公開対象の選別は既存の公開判定に従う。
- カードのカテゴリバッジを通常の文書配置に変更。画像削除後に残っていた狭い列指定を解消し、カード全体をリンクとして操作可能に。
- 記事一覧にタイトル・概要の絞り込みを追加。本文検索へのリンク、結果件数、該当なし時の解除操作も追加。
- 全記事へのリンクは静的HTMLにも出力する。JavaScriptが使えない場合でも記事一覧から移動できる。
- タブレット・スマホの言語選択とメニューを右側に配置。メニューはEscape、外側のクリック、リンク選択で閉じる。
- 記事本文と目次の文字サイズを調整。PCの目次は追従し、スマホでは本文前の開閉式の目次にまとめる。
- お問い合わせの入力欄は16px・高さ48px以上に調整。
- 色・余白・共通部品の新しい指定は `src/app/editorial.css` に集約。ルートレイアウトから既存スタイルの後に読み込む。

## 検証方法

- `npm run build:github-pages`：全記事を含むテスト用静的ビルド、既存の記事検証。
- `npm run check:export`：静的出力のリンク、言語・SEO設定など。
- Chromiumで日本語・英語・中国語のトップ、記事一覧、記事本文を320 / 390 / 768 / 1024 / 1440pxで確認。
- CSS・画像・JavaScriptが正常に取得できていることを確認したうえで、バッジと見出しの重なり、カード幅、横はみ出し、ブラウザーエラーを確認。
- 各言語の絞り込み、該当なし、解除後の入力欄へのフォーカス、モバイルメニューを確認。
- JavaScript無効でも一覧の全208記事へのリンクが存在することを確認。

## 手作業について

今回のデザイン反映に必須の手作業や環境変数の追加はありません。ロリポップの有効化作業は従来どおり `DEPLOYMENT.md` を参照してください。

医学的監修・権利確認のステータス、公開日・画像のJSON管理、GitHub Pagesのnoindex、本番の公開条件はこのデザイン変更の対象外です。公開前の既存の確認事項は各監査文書で引き続き管理します。
