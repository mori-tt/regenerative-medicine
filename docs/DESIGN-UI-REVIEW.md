# デザイン・UI見直し（2026-09-22）

## 変更内容

- 深緑・生成り・白を中心に、見出し、本文、補足、リンクの役割を統一。
- 本文はスマホでも16px、記事一覧の概要は14pxに。見出しの改行と行間も調整。
- トップの重複した「目的から探す」をテーマ別案内に集約。入門と記事一覧の入口を並べて表示。
- 日・英・中のトップに記事カードを4件表示。公開対象の選別は既存の公開判定に従う。
- カードのカテゴリバッジを通常の文書配置に変更。画像削除後に残っていた狭い列指定を解消し、カード全体をリンクとして操作可能に。
- 記事一覧にタイトル・概要の絞り込みを追加。本文検索へのリンク、結果件数、該当なし時の解除操作も追加。
- 全記事へのリンクは静的HTMLにも出力する。JavaScriptが使えない場合でも記事一覧から移動できる。
- タブレット・スマホの言語選択とメニューを右側に配置。メニューはEscape、外側のクリック、リンク選択で閉じる。
- 記事本文と目次の文字サイズを調整。PCの目次は追従し、スマホでは本文前の開閉式の目次にまとめる。
- お問い合わせの入力欄は16px・高さ48px以上に調整。
- 色・余白・共通部品の新しい指定は `src/app/editorial.css` に集約。ルートレイアウトから既存スタイルの後に読み込む。

## 検証方法

### フォントの再調整

記事カードに広げた明朝体と、大きく太い見出しが本文・ナビゲーションから浮いて見えるため、書体の役割を整理しました。

- ロゴとトップの主見出しは明朝体、記事・一覧・案内ページの見出しは本文と同系統のゴシック体。
- 記事カードは20pxからPC18px／スマホ17pxへ、太さは600から500へ調整。
- ページ見出しは最大36px／スマホ26px、本文中の見出しは25px／スマホ22pxに調整。
- 本文16px、記事概要14pxは維持。検索欄はラベルから継承していた太字を解除。
- フォントの役割は `globals.css` の `--sans` / `--heading` / `--serif`、サイズは `editorial.css` で管理。追加の外部フォント配信は使いません。

### 表示・ビルド確認

- `npm run build:github-pages`：全記事を含むテスト用静的ビルド、既存の記事検証。
- `npm run check:export`：静的出力のリンク、言語・SEO設定など。
- Chromiumで日本語・英語・中国語のトップ、記事一覧、記事本文を320 / 390 / 768 / 1024 / 1440pxで確認。
- CSS・画像・JavaScriptが正常に取得できていることを確認したうえで、バッジと見出しの重なり、カード幅、横はみ出し、ブラウザーエラーを確認。
- 各言語の絞り込み、該当なし、解除後の入力欄へのフォーカス、モバイルメニューを確認。
- JavaScript無効でも一覧の全記事へのリンクが存在することを確認。

## 手作業について

今回のデザイン反映に必須の手作業や環境変数の追加はありません。ロリポップの有効化作業は従来どおり `DEPLOYMENT.md` を参照してください。

医学的監修・権利確認のステータス、公開日・画像のJSON管理、GitHub Pagesのnoindex、本番の公開条件はこのデザイン変更の対象外です。公開前の既存の確認事項は各監査文書で引き続き管理します。

## 2026-10-03 実施の修正

- コントラスト：`--muted` を `#627065` へ変更し AA(4.5:1)を達成。低コントラストだったJSRM章カード・ヒーロー補足・purpose-links・メモ類も AA 相当へ引き上げ。
- フォント：モバイルの 7–9px 指定を解消。情報テキストは 11px 以上、装飾ラベルも 10px 以上を目安に globals/editorial 両 CSS を調整。
- タップターゲット：言語切替 44px・パンくず約 34px・見出しアンカー 18×35px・参照文献リンク・キーワードチップ等に余白を追加。
- ナビゲーション：内部リンクの外部リンク風「↗」表記を除去。言語スイッチャーの `aria-current` を `page` に修正。
- 用語ポップアップ：`aria-describedby` で定義を関連付け、Escape でトリガーへフォーカスを戻すようにした。
- 一覧フィルタ：`ArticleBrowser`/`StockReveal` をデータ属性＋DOM 制御へ変更し、カードを RSC ペイロードへ重複して持たない構成に（おすすめトグル・絞り込み・ストック開閉は従来どおり動作）。

## 2026-10-04 デザイン統一とUI修正

画面全体を「落ち着いた医療・学術メディア」の方向で再整備し、検証で見つかった UI バグも修正。

### デザインの統一

- `editorial.css` にデザイントークン（`--surface` / `--radius` / `--control-radius` / `--control-border`）を追加し、カード・パネル・フォーム・チップの角丸と枠線を統一。フォントは OS 標準の和文・中文スタックへ整理（外部フォント配信なし）。
- カテゴリカードを白基調＋統一角丸にし、5列グリッド（タブレット2列、スマホ横並び）へ。
- 記事カードの情報優先度を整理：カテゴリ＋おすすめバッジ → タイトル → 概要 → 監修・読了時間の順に。タイトルの 2 行クランプを外し、省略せず表示。
- ヘッダーを追従（sticky）化し、「はじめての方へ」「記事一覧」のプライマリナビを追加。現在ページに下線インジケーターと `aria-current="page"` を付与。英語ロゴの重複サブタイトルは非表示に。
- JSRM 特集のカード・本文・ナビ・ページャーも新トークンに合わせて再整備。

### UI の修正

- 記事一覧の絞り込み欄：`.browser-tools` とのクラス名ずれで未装飾だった入力欄を、ラベル付き・高さ56pxの検索 UI へ修正。クリアボタン、入力中のキーワードを引き継ぐ「本文も含めて検索」リンクを追加。
- スマホのカテゴリ選択：`CategoryNavigation` コンポーネントを新設し、PC はチップ群・モバイルは `<details>` 式ピッカーに変更（外部クリック・Escape・リンク選択で閉じ、JS 無効でも全リンク到達可能）。
- 「おすすめ」トグルと絞り込み欄の状態を MutationObserver で同期。「絞り込みを解除」はキーワードとおすすめの両方をリセットする。
- 用語ポップアップ：`role="region"` 化し `aria-labelledby` / `aria-controls` / `aria-describedby` を整備。Escape でトリガーへフォーカス復帰、フォーカスがポップ外へ出たら閉じる。
- ストック記事の開閉を `aria-expanded` + `aria-controls` 対応のパネルに。
- 記事の SVG 模式図：スマホで文字が 7px 級になる問題を、図を縮めずに横スクロールできる `ScrollableDiagram`（`role="region"`・キーボード操作可・スクロール案内文）で解消。
- 問い合わせ：英中ページの対象記事プリフィルに言語接頭辞（`/en/`・`/zh/`）が抜けていたのを修正。チェックボックスをテキストと分離し行間を確保。
- 論文図表の `img src` を `publicAsset()` 経由に変更（GitHub Pages の basePath で 404 になっていた）。1記事に同じ図版が2回出るとき論文図が二重に付いていたのも修正。
- モバイルの記事レイアウトが 760px 固定列で横はみ出ししていた問題を `minmax(0, 1fr)` で解消。
- 未監修カードの日付表示を「最終編集」に修正（公開日が来ていない記事に「公開 YYYY.MM.DD」と出ていた）。
