# 文献・著作権・医療広告の編集方針

公式資料の確認日：2026年9月22日。対象：全208記事の改稿・更新。本書は編集基準であり、全記事の確認完了を示すものではない。

AIと参照資料に基づく編集レビューは、医師による医学的確認や法律専門家による法的確認・承認ではない。スクリプトの合格、引用件数、JSONの整合性だけで「医学的に承認済み」「法的に問題なし」と表示しない。治療効果・安全性を保証せず、訴訟・紛争が一切起きないという保証もできない。

## 研究資料と確認範囲

- 各記事の主題に合う原著論文（一次研究）・系統的レビュー等（二次研究）を読み、独自の文章で説明する。重要な主張の直後に、対応する論文のDOI・PubMed・出版社等への直接リンクを置く。背景資料を並べただけで、その記事の主張が裏付けられたことにしない。
- 対象、研究方法、比較群、評価項目、追跡期間、限界・利益相反を読めた範囲で区別する。細胞・動物実験を人での有効性に置き換えず、承認、標準治療、保険適用も別々に扱う。撤回・訂正が判明した資料は再評価する。
- 医中誌・PubMedへの収載や検索ヒットは、研究の科学的妥当性や治療効果の認定ではない。医中誌も情報の正確性・有用性等を保証していない。[医中誌Web利用規程・第17条](https://www.jamas.or.jp/service/ichu/kitei.html)
- 法制度・保険・行政手続の記事は、対象制度の法令、厚労省の通知・公的案内を優先する。PubMed論文を形式的に追加して、日本の現行制度の根拠に代えない。

文献ごとのJSONの `accessedScope` は、実際に確認した範囲を記録する。併せて資料URL、確認日、記事内の対応する主張と未確認事項を残す。

| 確認範囲 | 記録・記述の基準 |
| --- | --- |
| 抄録（abstract） | 抄録を実際に読んだ場合。本文の方法・詳細な有害事象・補足資料まで確認したと書かない。 |
| 全文（full-text） | 正規にアクセスして本文を確認した場合。補足資料は別途確認の有無を残す。全文リンクの存在だけでは該当しない。 |
| 公式資料（official guidance） | 行政機関等の資料の該当箇所を確認した場合。版・改訂日・適用時点を記録する。 |

公開検索結果・書誌情報・検索スニペットだけを見た資料は候補扱いとし、抄録・全文を確認済みにしない。医中誌は書誌・抄録を検索するサービスであり、本文の閲覧にはリンク先の利用条件や別の入手手続が関わる。[医中誌Webの案内](https://login.jamas.or.jp/)、[法人版FAQ](https://www.jamas.or.jp/faq/houjin.html)

## 独自の説明と著作物の利用

研究上の事実を理解して独自に説明することを基本とする。抄録の全文転載・逐語訳・語句の置換や、図表・画像の大量転載で208記事を構成しない。出典リンクを付けただけで転載・翻案が許されるわけではない。

原文や図表を引用する場合は、公表済みであること、引用の必要性、公正な慣行、目的上正当な範囲、本文と引用部分の明確な区別・主従関係、出所表示を個別に確認する。条件を満たさない利用は権利者の許諾または利用可能なライセンスに従う。無料で読めることと再利用できることを区別する。[文化庁『著作権テキスト』令和8年度版・本文75頁](https://www.bunka.go.jp/seisaku/chosakuken/seidokaisetsu/pdf/94383901_01.pdf#page=78)

医中誌の契約はデータの自由な再公開の許諾ではない。法人・機関版規程は、無許諾でのデータ改変・外部頒布・出版・他DBへの流用・Web公開を制限し、代行検索・営利利用にも条件を置いている。規程上の例外をサイトへの転載許可と広く解釈しない。契約資料のAIへの投入・自動取得も、利用条件を確認せず行わない。[医中誌Web利用規程（2026年4月1日改訂）・第11～12条](https://www.jamas.or.jp/service/ichu/kitei.html)

## 医療広告・薬機法と監修表示

医療広告への該当性は、受診への誘引、医療機関等の特定可能性、医療に関する内容など、掲載の実態で確認する。医院との提携、掲載料・紹介料、予約リンク等がある場合、「研究解説」「一般情報」という名称や免責文だけで対象外と扱わない。虚偽・誇大表現、比較優良表現、効果に関する体験談、誤認を招く前後写真を避ける。[厚労省・医療広告等ガイドライン（2026年3月30日改正）第2・第3](https://www.mhlw.go.jp/content/001683594.pdf)

薬機法第66条は虚偽・誇大な効能等の表現や、医師等が効果を保証したと誤認させる表現を規制し、第68条は承認・認証前の対象製品の広告を禁止している。研究報告の紹介と製品の販売促進を区別し、「必ず治る」「副作用なし」などと書かない。医療広告の限定解除を薬機法上の広告許可と解釈しない。[厚労省・医薬品等の広告規制](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iyakuhin/koukokukisei/index.html)

監修予定者の名前や `planned` の記録は、就任への同意・記事確認の証拠ではない。本人の同意と、記事ごとの実際の確認を別々に記録する。実施前に「医師監修済み」と表示せず、確認者・対象版・確認日・確認範囲・利益相反を捏造しない。医学的確認と法的確認も別扱いとする。

## 残る人手の作業（運営者）

1. **契約・本文入手**：医中誌の契約種別と利用資格を確認し、必要な本文を出版社・所属図書館・正規の複写サービス等から入手する。認証情報を共有せず、営利利用・代行検索・AI利用等の不明点は提供元に確認する。本文を読めた文献だけ確認範囲を更新する。[医中誌複写サービス](https://www.jamas.or.jp/service/copy/copy.html)
2. **権利処理**：転載・翻訳・図表利用が必要な箇所について、引用条件、ライセンス、契約条件を確認し、必要な許諾と利用範囲を保存する。未解決の素材は掲載しない。
3. **記事ごとの医師確認**：予定者本人から就任・氏名表示の同意を得たうえで、各記事の対象版と根拠資料を渡し、医学的内容・限界・リスク表現の実確認と修正を記録する。208記事を一括して確認済みにせず、未確認記事はその状態を維持する。
4. **広告・医院関係の法的確認**：運営主体、医院との資本・業務関係、報酬、商品名、予約・購入導線を法律専門家に提示し、記事とサイト全体の広告該当性、薬機法、必要表示を確認する。自由診療の内容・費用・主なリスクや未承認医薬品等の追加情報、限定解除要件は実際の表示に照らして判断し、確認範囲・日付・修正内容を保存する。[厚労省・医療広告等ガイドラインQ&A（2026年3月改訂）](https://www.mhlw.go.jp/content/001683595.pdf)。公開・更新時には[厚労省の公式掲載ページ](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iryou/kokokukisei/)で改訂の有無も確認する。
